# TWO_SAMPLE-T_Test
Independent Two-Sample t-Test Analysis



Project Overview:
This project performs an Independent Two-Sample t-Test to determine whether there is a statistically significant difference between the means of two independent groups.

Objectives:
1. Generate simulated data for two independent groups.
2. Calculate sample means and sample variances.
3. Calculate pooled sample variance.
4. Calculate the t-statistic and p-value.
5. Calculate a 95% confidence interval.
6. Make a statistical decision based on alpha = 0.05.

Technologies Used:
- Python
- NumPy
- SciPy
- Statistical Hypothesis Testing

Statistical Parameters:
Group 1 Sample Size: 30
Group 2 Sample Size: 30
Group 1 Population Mean: 105
Group 2 Population Mean: 98
Common Standard Deviation: 10
Confidence Level: 95%
Significance Level: 0.05

Hypotheses:

H0: μ1 - μ2 = 0
There is no significant difference between the population means.

H1: μ1 - μ2 ≠ 0
There is a significant difference between the population means.

Methodology:
1. Generate two independent normally distributed samples.
2. Calculate the sample means.
3. Calculate sample variances.
4. Calculate pooled variance.
5. Calculate the standard error.
6. Calculate the t-statistic.
7. Calculate the two-tailed p-value.
8. Calculate the 95% confidence interval.
9. Compare the p-value with alpha = 0.05.
10. Make the final decision.

Conclusion:
If the p-value is less than 0.05, we reject H0 and conclude that there is a statistically significant difference between the two population means.
